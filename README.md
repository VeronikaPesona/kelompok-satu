## 3. Deskripsi Proyek

Program ini adalah penganalisis angka yang berfungsi menganalisis sejumlah angka yang dimasukkan pengguna program.

---

## 5. Input

Program ini menerima:
- Jumlah angka yang ingin dianalisis
- Masukkan angka yang ingin dianalisis

---

## 6. Proses

Pengguna program memasukkan beberapa angka acak.
- Jika angka lebih dari 0, maka dikategorikan sebagai positif.
- Jika angka kurang dari 0, maka dikategorikan sebagai negatif.
- Jika angka habis dibagi 2, maka dikategorikan sebagai genap.
- Jika tidak habis dibagi 2, maka dikategorikan sebagai ganjil.
- Setiap angka dijumlahkan untuk mendapatkan total.
- Setelah semua angka dimasukkan, program menghitung rata-rata.

---

## 7. Output

Program ini akan menampilkan:
- Jumlah angka positif 
- Jumlah angka negatif 
- Jumlah angka genap
- Jumlah angka ganjil
- Total seluruh angka
- Nilai rata-rata
